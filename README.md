# Nykaa Digital Marketing Campaign Performance Analysis - Excel

## Project Overview

Nykaa Digital Marketing Campaign Performance Analysis is an Excel-based data analytics project designed to evaluate digital marketing campaign performance. The project focuses on analyzing campaign revenue, costs, clicks, impressions, conversions, and marketing channels to understand campaign effectiveness and audience engagement.

The dashboard transforms raw marketing data into meaningful business insights using Excel data analysis and visualization techniques, helping evaluate campaign performance and identify opportunities for optimization.

## Project Objectives

- Analyze digital marketing campaign performance using Excel.
- Track key performance indicators such as revenue, ROI, CTR, and conversions.
- Compare the performance of different marketing channels.
- Identify high-performing audience segments and campaigns.
- Create an interactive dashboard for campaign monitoring.
- Support data-driven marketing decisions and budget planning.

## Tools & Technologies

- **Microsoft Excel** – Data analysis and dashboard development
- **Pivot Tables** – Data summarization and analysis
- **Pivot Charts** – Visual representation of campaign metrics
- **Excel Formulas** – KPI calculations and performance measurement
- **Data Cleaning** – Preparing campaign data for analysis
- **Data Visualization** – Presenting campaign insights through charts and dashboards

## Dashboard Components

The dashboard presents key marketing performance metrics, including:

| Component | Purpose |
|---|---|
| Revenue Analysis | Evaluates revenue generated by marketing campaigns. |
| ROI Analysis | Measures return on marketing investment. |
| CTR Analysis | Evaluates audience engagement with campaign advertisements. |
| Clicks and Impressions | Measures campaign reach and engagement. |
| Leads and Conversions | Tracks potential customers and conversion performance. |
| Channel Performance | Compares the performance of different marketing channels. |
| Audience Analysis | Identifies high-performing customer segments. |

## Key Performance Indicators (KPIs)

- Total Revenue
- Campaign Cost
- Profit
- Return on Investment (ROI)
- Click-Through Rate (CTR)
- Clicks
- Impressions
- Leads
- Conversions
- Cost per Click (CPC)

## Business Questions Explored

The project analyzes questions such as:

1. How effectively are marketing campaigns generating revenue?
2. Which marketing channels perform best?
3. What are the overall ROI and CTR?
4. Which audience segments generate the strongest results?
5. How do clicks, impressions, leads, and conversions reflect campaign performance?
6. Which marketing channels offer opportunities for optimization?
7. How can campaign metrics support marketing budget planning?
8. How can an interactive dashboard simplify campaign performance monitoring?

## Key Findings

- Influencer marketing emerged as the best-performing channel in the analysis.
- College Students were identified as the top-performing audience segment.
- The campaign analysis recorded an ROI of 2.77 and a CTR of 8.53%.

## Data Preparation

The raw campaign data was cleaned and organized before analysis. Excel formulas, Pivot Tables, and Pivot Charts were used to calculate key metrics, summarize performance, compare marketing channels, and develop the dashboard.
