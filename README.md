## Nykaa Digital Marketing Campaign Performance Dashboard – Excel

## Project Overview

This project is an interactive Digital Marketing Campaign Performance Dashboard created using Microsoft Excel. The dashboard analyzes marketing campaign data and presents key information about revenue, ROI, clicks, impressions, conversions, and marketing channel performance.

The main objective of this project is to transform raw campaign data into meaningful business insights using Excel data analysis and visualization techniques.

## Tools Used

- Microsoft Excel (Advanced)
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- KPI Analysis
- Dashboard Design
- Data Visualization

## Dashboard Features

The dashboard provides an overview of:

- Total revenue and campaign costs
- Profit and return on investment (ROI)
- Click-through rate (CTR)
- Clicks and impressions
- Leads and conversions
- Cost per click (CPC)
- Marketing channel performance
- Audience segment performance
- Campaign effectiveness

## Key Analysis

The dashboard can be used to analyze:

- Overall marketing campaign performance
- Revenue and ROI across marketing channels
- Campaign engagement and conversion trends
- Performance of different audience segments
- Effectiveness of influencer marketing
- Opportunities for marketing budget optimization
- Key performance indicators for campaign monitoring

## Data Preparation

The campaign data was cleaned and analyzed using Excel. Pivot Tables, Excel formulas, charts, and KPI calculations were used to summarize campaign performance and develop an interactive dashboard.

## Key Findings

- Influencer marketing emerged as the best-performing channel in the analysis.
- College Students were identified as the top-performing audience segment.
- The overall campaign ROI was 2.77, with a CTR of 8.53%.
